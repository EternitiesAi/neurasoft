Use existing dependencies; no installation is required.

- Set NODE_PATH to an existing directory containing Sharp and Playwright.
- node tools/build_shape_media.cjs
- python assets/papers/when-history-changes-the-agent/verify_analytic_examples.py
- python tools/build_history_paper.py (ReportLab and Windows Georgia/Calibri fonts)
- python tools/package_history_paper.py
- python build.py
- Run the targeted Python site, article, reflection, continuity, edition, search and branding tests; node --test tests/search.test.cjs.

- python tools/stage_cloudflare.py

Deploy only artifacts/cloudflare to the existing neurasoft-research Pages project. Verify a preview before production, then verify the custom domain and public inbox. Do not deploy historical main or the repository root.
